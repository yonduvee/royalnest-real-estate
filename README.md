#  RoyalNest - Premium Real Estate Platform


##  Overview

RoyalNest is a modern full-stack real estate platform where users can explore premium properties, view property details, book properties, and manage their accounts.

Admins can manage properties, users, and bookings through a dedicated dashboard.



##  Features


###  User Features

- User registration and login
- JWT authentication
- Browse properties
- View property details
- Book properties
- View booking history
- Save favorite properties
- Update profile
- Change password



###  Admin Features

- Secure admin dashboard
- Add new properties
- Upload multiple property images
- Manage properties
- Update properties
- Delete properties
- Manage bookings
- Manage users
- Dashboard statistics
